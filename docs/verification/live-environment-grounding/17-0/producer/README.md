# Real plan producer qualification

These fixtures were generated by released producer executables, using only the built-in `terraform_data` resource and local temporary directories. No cloud provider was loaded and no AWS account was contacted. The local `apply` step creates synthetic local test state only. It is not a DeployWhisper capability and does not authorize infrastructure mutation.

Qualified producer profiles: Terraform 1.17.2 and 1.16.7; OpenTofu 1.13.9 and 1.12.12, Darwin ARM64. All emitted plan JSON `format_version: "1.2"` and embedded prior state `format_version: "1.0"`. The state format version is distinct from the plan format version. Only plan format 1.2 is qualified here. Earlier synthetic shape probes do not qualify other producer formats.

The stored files are projected synthetic plan exports: producer versions, addresses, actions and synthetic `id`/`input` fields only. No raw Terraform/OpenTofu state, binary plan, cloud identifier, credentials or downloaded executable is committed. Synthetic local UUIDs are not estate identifiers. Generation and projection are reproducible in `generate.py`; UUIDs vary across runs and each actual fixture digest is recorded.

```sh
./.venv/bin/python docs/verification/live-environment-grounding/17-0/producer/generate.py
./.venv/bin/python -m unittest discover -s docs/verification/live-environment-grounding/17-0/producer -v
./.venv/bin/ruff check docs/verification/live-environment-grounding/17-0/producer
./.venv/bin/ruff format --check docs/verification/live-environment-grounding/17-0/producer
./.venv/bin/bandit -r docs/verification/live-environment-grounding/17-0/producer --severity-level medium --confidence-level medium
```

The executable archives are downloaded from official HTTPS release origins and verified against their official SHA256 manifests. The downloader permits only canonical release/CDN hosts with bounded redirects; archive signature verification is not claimed. The final modified downloader was rerun successfully for all four profiles. Executables, intermediate state and binary plans are removed when each temporary directory closes.

Three tests pass, covering all four real producers, nested module prior state, updates/deletes/creates, absent/null prior-state fallback to `change.before`, unknown state when neither source is present, minimal synthetic projection and rejection of noncanonical downloader URLs before connection. Scoped Ruff passes; Bandit has no medium/high findings (two low subprocess informational findings). Official release discovery sources: [Terraform releases](https://github.com/hashicorp/terraform/releases), [OpenTofu releases](https://github.com/opentofu/opentofu/releases). [Terraform JSON format](https://developer.hashicorp.com/terraform/internals/json-format) documents the independent plan and state format representations.

This proves producer layout and extraction mechanics. It does not qualify AWS provider schema mappings or live reads. Those are separately owned capabilities, not evidence inferred from local built-in resources.
