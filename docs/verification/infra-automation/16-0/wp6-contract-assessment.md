## Draft protocols and owned proof

Version-1 wire proposals are closed: reject unknown keys, major versions, enum states, capability names and unsupported authorization kinds. A capability intersection cannot remove fencing, online authority checks or exact-byte requirements. Typed opaque references carry no shell/expression substitution. All timestamps are UTC; IDs are opaque; content digests are algorithm-versioned. Final exact field names, bounded sizes, cryptographic parameters, concurrency/cursor semantics and digests await owning-story freeze.

Every exact-plan action binds authorization kind, workflow/revision, inputs, repository/immutable IaC commit, project/workspace/environment, canonical target/receiver, report bytes/schema/digest, policy version/result/digest, unit/wave digest, screened artifact/redaction identity, raw-local custody/digest, payload, shortest deadlines and restore/authorization epochs. Separate pipeline workflow identity/ref also requires protection; it is not the IaC SHA. Upload-only `advisory_request` can lack repository identity honestly and cannot authorize apply. No raw plan/state or credential belongs in this packet.

Run enum proposal follows architecture: queued, running, waiting_approval, ready_handoff, handing_off, external_running, succeeded, failed, stopped_by_gate, rejected, expired, timed_out, cancelled, delivery_unknown. Attempts: pending, claimed, running, succeeded, failed, timed_out, cancelled. Unknown state denies mutations. Gate stop, human rejection, evidence expiry, deadline timeout and cancellation remain distinct. `delivery_unknown` allows only authorized read/reconciliation/cancel-request and preserves the canonical target lock; no local timeout is external completion. Retry-safe local work creates a new monotonic attempt/fence; external uncertainty never silently retries action.
